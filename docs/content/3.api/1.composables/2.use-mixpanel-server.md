---
title: useMixpanelServer
description: Access the shared Mixpanel Node client in Nitro.
---

`useMixpanelServer()` returns the Node SDK instance used by Nitro. It is auto-imported in server routes, plugins and utilities.

## Usage

```ts
const mixpanel = useMixpanelServer()
```

For an explicit import:

```ts
import { useMixpanelServer } from '#mixpanel/server'
```

## Type

```ts [Signature]
function useMixpanelServer(): MixpanelServer
```

```ts [Type import]
import type { MixpanelServer } from 'mixpanel-nuxt/config'
```

## Return value

`MixpanelServer` exposes the [Mixpanel Node SDK](https://docs.mixpanel.com/docs/tracking-methods/sdks/nodejs). The instance is initialized on first use and reused by subsequent calls.

SDK methods retain their callback signatures. The module does not convert them to Promises. See [Nitro](/integration/nitro) for a handler that waits for delivery.

## Shared state

User identity must be supplied with each operation. The shared instance must not hold request-specific identity or properties.

## Availability

Server tracking is enabled by default. Calling the accessor when `server.enabled` is `false` throws. The server token is independent of the browser token.

Node and serverless Node are supported; edge presets are not covered.
